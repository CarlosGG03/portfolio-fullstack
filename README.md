# Portfolio Full Stack

Full Stack portfolio application built to demonstrate modern software
engineering practices, cloud technologies, backend development and frontend
architecture.

## Architecture

The application is organized as a monorepo containing:

- Next.js frontend
- Python FastAPI backend
- ASP.NET Core backend
- PostgreSQL database
- Docker infrastructure
- Automated testing
- CI/CD pipelines
- Cloud deployment

## Main Technologies

### Frontend

- Next.js
- React
- TypeScript
- Tailwind CSS
- shadcn/ui

### Backend

- Python
- FastAPI
- .NET
- ASP.NET Core

### Database

- PostgreSQL

### Infrastructure

- Docker
- Docker Compose
- GitHub Actions
- Azure

## Architecture Principles

This project follows:

- Clean Code
- SOLID
- Clean Architecture
- Separation of Concerns
- Dependency Inversion
- YAGNI
- DRY when appropriate

The project intentionally avoids unnecessary complexity.

Technology and architecture decisions should be justified by actual
requirements.
