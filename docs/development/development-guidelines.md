# Development Guidelines

## General Principles

The project follows:

- Clean Code
- SOLID
- YAGNI
- Separation of Concerns
- Dependency Inversion

## Code Quality

Code should be:

- Readable
- Testable
- Explicit
- Small and focused
- Easy to modify

## Naming

Names should describe intent.

Avoid:

data
temp
value
thing
manager
